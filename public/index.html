설정

수집 대상은 config/sources.json에 추가합니다. GitHub Actions가 해당 RSS/URL을 읽어 정적 JSON으로 게시합니다.

데이터 수집 설정

GitHub Actions가 매일 오전 7시(KST)에 데이터를 갱신합니다.

새 국가/기관 추가

config/sources.json에 source, region, type, url, keywords를 추가한 뒤 Actions를 다시 실행하세요.

사이트에서 바로 적용

관리자 GitHub 토큰으로 config/sources.json을 커밋하고 수집 워크플로우를 실행합니다.

AI API 설정

선택한 AI 제공자의 API key를 GitHub Repository Secret에 암호화 저장합니다. 키 값은 사이트에 저장되지 않습니다.

저장된 OpenAI key는 GitHub Secret에만 보관됩니다.

GitHub classic token 입력 후 AI 설정을 저장할 수 있습니다.

수집 소스 관리

URL 유형 URL 입력 시 자동 분류

수집 데이터 관리

LLM 프롬프트/모델 변경을 테스트할 때 실제 GitHub Actions 수집을 수동으로 실행합니다. 기존 데이터는 목록에서 확인하거나 삭제 후 저장할 수 있습니다.

수동 수집 실행은 저장된 수집 소스 기준으로 GitHub Actions를 실행합니다.

토큰은 브라우저 메모리에서만 사용되며 저장하지 않습니다.
